## 💾 How to save and fetch results (commands)

1) Save the harness console output to a text file (PowerShell):
   - From repo root (Windows PowerShell):
     ```powershell
     $env:PYTHONPATH = Get-Location
     .\.venv\Scripts\python.exe -m tests.run_suite 2>&1 | Tee-Object -FilePath .\test_output.txt
     ```
   - The full console log will be in `.\test_output.txt`.

2) Save pytest results as JUnit XML (for CI):
   ```powershell
   $env:PYTHONPATH = Get-Location
   .\.venv\Scripts\python.exe -m pytest --junitxml=results.xml -q
   ```
   - `results.xml` will contain test summary and each test case result.

3) Save the full harness return results (JSON) including `audit_log`:
   - Quick one-liner to capture JSON results:
     ```powershell
     $env:PYTHONPATH = Get-Location
     .\.venv\Scripts\python.exe -c "import os, json; from tests.run_suite import run_suite; r=run_suite(os.path.join(os.getcwd(),'tests','integration','transfer_cases.yaml')); open('results.json','w', encoding='utf-8').write(json.dumps(r, indent=2))"
     ```
   - Output will be written to `results.json` (includes `audit_log` per case).

4) Capture any debug output (trace-level):
   - Add or temporarily enable debug logs:
     - Add at top of run_suite.py:
       ```python
       import logging
       logging.basicConfig(level=logging.DEBUG)
       ```
     - Or set logging from PowerShell script that sets `PYTHONPATH` and runs the harness.
